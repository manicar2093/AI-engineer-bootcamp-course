# Fine tuning technics

## Standard fine-tuning

Adjust all parameters in LLM to increase performace to a specific task. Extremely effective, but also expensive.

Change weights of a pre-trained model to fit a task

When to use: Similar tasks, medium to large datasets

## Low rank adaption (LoRA)

It is a paremeter-efficient fine-tuning: instead of being intrusive (updating all weights), it only adds a small, low-rank matrices to specific layer reducing the number of parameters that need to be updated

When to use: Limited resources, multi-task adaption, avoiding catastrophic forgetting

## Supervised fine-tuning (SFT)

It trains a model on a new dataset under supervision (including demostration data, prompts, responses, etc)

When to use: Labeled datasets, task requiring high accurancy

## Reinforcement Learning From Human Feedback (RLHF)

It is training a model with the help of humans. Facilitates continuous improvement based on human input

When to use: Aligning outputs with human preferences, dialogue generation, content creation
